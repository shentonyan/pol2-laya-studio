# 2026-09-24 · 蒸馏 v1：用 Jev + 本地 LLM 当老师训练 PoL2 专用 Laya 判别模型

> **诚实条款**：本次实验没有人工标注。所有「准确率」都是与某个参照的一致率：老师共识、一个未参与训练的独立模型（gemma4:26b），或按构造推出的标签。这些都不等于「判得对」。所有样本都是合成文本，不描述任何真实个人。负结果如实列出。

## 1. 做了什么

| 步骤 | 内容 |
|---|---|
| 样本 | 5 个 PoL2 场景（爱语辨识、谄媚第三方条件、爱语擂台、威胁归因、伦理对齐协议代理检查），由 `gemma4:26b` 合成 1512 条 state；另有 16 条种子样本 |
| 结构性孪生 | 爱语擂台：每对改写都有 A/B 互换孪生。谄媚：每个主张 × 2 种归属（本人 / 第三方）× 3 种回复（附和 / 反驳 / 回避） |
| 老师 | `jev:openjev`、`ollama:qwen2.5:7b`、`ollama:llama3.1:8b`。本地模型用 JSON Schema 约束解码，采样 3 次，以投票频率作为分布 |
| 聚合 | 每个老师先做 ε=0.02 平滑再混合；多数票比例 < 2/3、noul 共识落在 [0.35, 0.65]、choice 前两名差 < 0.1 的题目不进训练。同一回复的两种归属、A/B 互换孪生先合并再聚合 |
| 排除 | qwen 在 `syco.sycophantic` 上对 303 条全部回答「否」（常数答案），在 `syco.respectful` 上也几乎只给一个答案，因此它不参与谄媚场景（`--exclude ollama:qwen2.5:7b=syco.*`） |
| 切分 | 按 `group_id` 切分，同一主张或同一对改写不会同时出现在训练集和测试集。训练 1292 行（2811 道题，其中 381 道留出做温度校准），测试 227 行 |
| 学生 | `convaiinnovations/laya` 的 multilingual 基座（mmBERT-base，322M），单卡 RLCD 微调 4 个 epoch，约 2.5 分钟；拟合温度 (choice, score, noul) = (1.12, 0.90, 1.18) |

## 2. 三种参照下的结果（整体准确率）

| 系统 | 老师共识 test（227 条） | 独立裁判 gemma4:26b（227 条） | 构造 gold：全新谄媚样本（300 条） |
|---|---:|---:|---:|
| 基础 multilingual（零样本） | 0.514 | 0.491 | 0.638 |
| **学生 laya-pol2-20260924-0504** | **0.859** | **0.861** | **0.770** |
| qwen2.5:7b | — | 0.815 | — |
| llama3.1:8b | 0.913 | 0.878 | 0.754 |
| Jev | 0.921 | 0.900 | 0.929 |

- 老师共识 test：Jev 和 llama 本身参与了这份共识，分数天然偏高，只能作为参照。
- 独立裁判：gemma4:26b 没有参与训练标签，但测试样本是它自己生成的，可能偏爱自己的文本。
- 构造 gold：300 条是在训练结束后另外生成的，放在训练目录之外，从未打过标签，也从未参与训练。「是否谄媚」「回复类型」直接由主张真假和回复类型推出，不经过任何模型判断。生成模型偶尔会写错回复类型；Jev 在这份 gold 上最高只到 0.93，可以粗略当作这份 gold 的质量上限。

## 3. 校准与不变性

| 系统 | ECE（独立裁判） | ECE（构造 gold） | 归属效应 平均 \|ΔP(谄媚)\|（150 对全新样本） | A/B 互换一致率（26 对） |
|---|---:|---:|---:|---:|
| 基础 multilingual | 0.342 | 0.130 | 0.067 | 0.115 |
| **学生** | **0.046** | **0.055** | **0.019** | **1.000** |
| llama3.1:8b | 0.081 | 0.120 | 0.084 | 1.000 |
| Jev | 0.061 | 0.047 | 0.014 | 1.000 |

- 学生的概率校准与 Jev 同属最好的一档，明显好于本地 LLM 裁判。
- 同一条回复只改变归属（「我觉得…」/「我同事说…」）时，学生的判断几乎不变，接近 Jev。
- 两个改写对调位置后，学生的判断 100% 跟着对调；基础模型只有 12%。

## 4. 负结果

**学生没有学会在全新样本上判断「是否谄媚」。**

| `syco.sycophantic`（构造 gold，300 条） | 准确率 |
|---|---:|
| 一律回答「否」（多数类基线，236/300） | 0.787 |
| 基础 multilingual | 0.717 |
| **学生** | **0.787** |
| llama3.1:8b | 0.870 |
| Jev | 0.933 |

学生的准确率恰好等于多数类基线，说明在这道题上它基本等同于一律回答「否」。原因：排除 qwen 之后，训练集里「谄媚 = 是」只有 14 条（约 6%）。

同一批样本上的 `syco.reply_type`，学生是 0.750（多数类基线 0.379，llama 0.621，基础模型 0.549）：它能分辨附和、反驳、回避这三种形式，但还不会把「附和了一个错误主张」判为谄媚。

其他弱项（与独立裁判的一致率）：`lovelang.warmth` 0.61，`lovelang.stance` 0.73，`syco.reply_type` 0.68。

## 5. 老师自身的问题（先检验尺子）

- qwen2.5:7b 在谄媚场景出现常数答案，已排除；它在 A/B 互换一致率上也最低（0.90，其余老师 ≥ 0.98）。
- 老师两两一致率只有 0.82–0.84。分歧集中在 `eap.honest`（32%）和 `lovelang.truthful`（22%），很可能是题目本身把「说真话」和「说得好听」混在一起了。
- 构建 gold 时，同一回复的两种归属、A/B 互换孪生都合并平均过，所以老师的归属偏差和位置偏差不会直接进入训练标签。

## 7. 复现

```powershell
cd ~\pol2-laya-studio
$py = "$HOME\laya-env\Scripts\python.exe"
& $py -m distill seeds
& $py -m distill generate --model gemma4:26b --per-scenario 300
& $py -m distill label --teacher jev --workers 6
& $py -m distill label --teacher ollama:qwen2.5:7b
& $py -m distill label --teacher ollama:llama3.1:8b
& $py -m distill build --teacher jev --teacher ollama:qwen2.5:7b --teacher ollama:llama3.1:8b --exclude ollama:qwen2.5:7b=syco.*
& $py -m distill train
powershell -ExecutionPolicy Bypass -File .\scripts\run_autogold.ps1
```
